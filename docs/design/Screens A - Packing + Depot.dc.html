DESKTOP ↔ PHONE
Same slice model, different density: desktop gets the sidebar (places, saved slices), 44px rows, 8 columns and keyboard bindings; phone folds columns into a 2-line row — whereabouts stays top-right, always visible. Past 75em (1200) this desktop layout centres at max-width 1120.
DOMAIN RIGOR
Depot shows no packing status — that belongs to a trip. Home world shows HOME path + whereabouts only. Gear on a trip keeps its home path (muted) and gains the amber ▸ trip marker.
