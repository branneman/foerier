Not drawn. PERSON mode partitions gear, and a bucket with no gear is not a group of anything — the same refusal as ● 0/0 PIECES. E8 — THE ORPHANED INDENTREDRAWN
A group header survives ○ LEFT while anything at any depth beneath it does. Its count is contents at any depth (A4, §3.4) and its ▲ counts at any depth (A6); the filter is the same question asked of the same subtree, and a header hidden while its own 9/12 says three are left is the header lying about its contents — round 2's fault. So the orphan is unreachable: a nested group always has its ancestor above it, and the indent stays what it is, a fact about the tree. The header's own rows may all be gone; it then sits directly over the nested header, which is the true picture. One predicate; the test pinning the orphan retires. Frame at 03.

What is redrawn is the meta: PER-PERSON · NO PIECES, muted, in place of a 0/0 nobody asked for. True in both ways it happens (no Participants yet; every Piece removed). No cluster — zero circles are not a control — and the row is inert: nothing to set, nothing to move, so the body opens nothing. Frame at 04.
E10 — SET EVERYONE'S NBLESSED

This is the rail's own rule (A15: tapping the current stage writes nothing, because a redundant write moves the stamp LWW compares) applied to N registers at once — the one surface where a single tap authors N writes, so the one where a redundant write can silently beat a genuine concurrent one. The control's meaning does not change: everyone ends at the tapped status. §1's N ops in one batch is amended to say what N counts. Specimen at 06.

THE TOKEN WINS (E5)
Two board numbers differed from the app's tokens and were built to the token. Rather than two more code-authored lines in §1, this round states the rule once: where a board's number differs from a shared token, the token wins and the difference is recorded at the token, for a round that can change it everywhere. The DISPLAY row's 34 on desktop and the Spacing row's 20 at Roomy both take drawn but not built. §1's Widths bullet stops carrying its own gutter; §1's title line reads 28/34 and nothing else.
WHY NOT MAKE THE TOKEN GROW
A Desktop title step is a real design question — the Depot desktop frame draws its title at 28 too, so the boards never took it either; only the table said it. Deciding it here for one screen would be the odd-one-out the code refused. Left as the token's open item, marked, with both answers legal: add the step to the token and every title grows, or delete the parenthesis. Neither is F4's to take.
12 BETWEEN CARDS (E6)
From Roomy up the group is a card — 12px radius, 1px rule — and two cards need air: at 0 the corners make a pinched waist, at 8 they still read as one shape, at 12 they separate. 12 is already the top of the scale's between cards range, so no new number enters the system. Below Roomy the list is edge-to-edge, the cards have no corners, and the gap is 0 as every 393 frame draws.

WHY THE SKIP IS THE RAIL'S RULE
A15: tapping the current stage writes nothing, because a redundant write moves the stamp LWW compares. A redundant trip.piece_status_set carries a newer HLC than the register holds, so it beats — and silently discards — a genuine concurrent write from another Device. On the pill and the rail that is one register at risk; here one tap authors N, so it is the surface where the rule matters most.
