10 — SCOPE TAG (LATER)
THE TAG

61 PIECES · EST 48.2 KG LATER S8 · PIECES API FIELD

TAG SITS INLINE AFTER THE ELEMENT IT SCOPES; WHERE THAT ELEMENT IS A SEGMENT OF A COMPOSITE LINE, THE MVP VARIANT IS DRAWN ALONGSIDE (AS ABOVE).
RULE
LATER marks an element that is drawn final and decided, but not MVP: the ledger group on Gear detail (story 33) and every weight total (story 16). Build the MVP without tagged elements; their design does not change when they land. Dashed border = not yet committed, the same grammar as draft cards and future journey chips. The tag never recolours or dims the element it scopes — the element stays exactly as it will ship.
It is a scope marker, not a status: never ▲, never amber, never on interactive states. Anything untagged on the boards is MVP.
Two text variants, same anatomy: a slice number (S9 on Find’s per-person card — restaged from S8 · PIECES at the S8 round) marks an MVP element that lands with a later slice — decided and final, not Later, not regressed (Find's per-person card). API FIELD marks copy blocked on an endpoint field (the join names) — omitted until the field exists, never faked. LATER alone stays post-MVP.
11 — WHEREABOUTS VOCABULARY · TWO QUESTIONS, TWO WORDS
THE GLYPH = WORLD · THE WORD = THE ANSWER
⌂ HOMEWORLD ONLY — CHIPS, COLUMNS
▸ ON TRIPWORLD ONLY — AMBER, EVERYWHERE
⌂ ATTIC ▸ CRATE BRESIDENCE — WHERE IT LIVES
⌂ LOOSERESIDENCE — LIVES NOWHERE (LEGITIMATE, NOT AN ERROR)
▲ LAST SEEN: …UNACCOUNTED — ATTENTION CLASS
RULING — SETTLED
Two words answer two different questions and both are correct — on the same screen if it asks both. ⌂ HOME answers which world is this in (§82's two-worlds indicator: ⌂ muted vs ▸ amber); LOOSE answers where does it live — the glossary term for residing nowhere. The glyph always names the world; the word after it names the residence where the surface answers residence (a path, or LOOSE), and the bare world (HOME, ON TRIP) where it only answers world. HOME never names a residence; LOOSE never stands alone as a world — it is written ⌂ LOOSE. Find showing the ⌂ HOME chip beside a ⌂ LOOSE line is the grammar working, not a contradiction.
